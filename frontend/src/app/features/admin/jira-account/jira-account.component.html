Cara membuat token

  1. Login sebagai akun yang akan dipakai bot, lalu buka Atlassian API tokens
  2. Klik Create API token, beri nama dan masa berlaku.
  3. Copy token-nya, lalu tempel di form ini.

Token punya masa berlaku. Ganti sebelum kedaluwarsa supaya polling dan reminder tidak berhenti.
